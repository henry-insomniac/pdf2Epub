# 使用私有 R2 交付成功 EPUB

生产环境将成功 EPUB 上传到 Cloudflare R2 私有 bucket，并在本地副本删除后把对象 key 保存到当前进程内的任务状态。用户仍从受会话保护的 `/api/v1/jobs/{id}/download` 发起下载；服务校验任务和登录状态后生成短期 S3 签名 URL，以 `302 Found` 将浏览器直接重定向到 R2。

该方案把大型文件传输从单台新加坡 VPS 的公网出口移到对象存储网络，同时不把 bucket 或对象永久公开。R2 token 只授予指定 bucket 的对象读写权限；签名 URL 有效期默认 15 分钟，并视为临时 bearer token。任务保留期仍为一小时，到期和优雅退出时删除远端对象，bucket 生命周期规则用于兜底异常退出产生的孤儿对象。

R2 是可选外部边界。未配置时保持原有本地下载；已配置但单次上传失败时，转换仍成功并保留本地产物，同时产生可见降级警告和内部错误日志。这样外部存储短时故障不会丢失已经通过 EPUBCheck 的有效出版物。

未采用对当前 Cookie 下载接口直接配置 CDN `Cache Everything`，因为每个任务产物通常只下载一次，缓存命中率低，而且缓存命中可能绕过源站会话检查。未采用公开 R2 bucket，避免把任务 ID 当作唯一访问控制。
