# 自适应选择可重排或固定版式 EPUB

## 决策

服务提供 `auto`、`reflowable`、`fixed` 三种转换模式，默认使用 `auto`。自动模式抽样检查 PDF 页面的文本层、主图片覆盖率和跨页重复文本：存在可靠正文文本时沿用可重排 EPUB；正文主要位于页面图片中，且文本层为空或只是跨页重复覆盖层时，生成固定版式 EPUB。

固定版式将每个源页面渲染为一个 JPEG 页面，XHTML 设置与图像一致的 viewport；OPF 声明 `rendition:layout=pre-paginated`、`rendition:spread=both`、从左到右翻页，并为奇偶页面声明 `page-spread-right` / `page-spread-left`。它保留原版面和双页阅读顺序，但不提供 OCR、自由调字号或可靠文字搜索。

明确选择 `reflowable` 时，如果预检判断正文位于页面图片中，任务失败并提示改用固定版式，避免把水印或 OCR 噪声伪装成正文。明确选择 `fixed` 时不依赖文本层，直接渲染全部页面。

## 原因

单一可重排输出无法同时覆盖可靠文本图书和图片型复杂版式。把整页图片作为普通插图并继续输出不可靠文本层，会造成页面重复、水印独占页面和错误成功语义。固定版式是无 OCR 条件下保留此类 PDF 内容完整性的可验证路径。

## 影响

- ADR 0001 仍适用于可重排分支，但不再是服务唯一输出模型。
- 固定版式文件通常较大，继续通过私有 R2 交付。
- 阅读器决定最终单双页显示；支持 EPUB spread 语义的阅读器在横屏或宽窗口中可展示左右双页。
- EPUBCheck 仍是两种版式共同的成功门槛。
