# V1 验收矩阵

本文档定义 `btc-server` 首个可交付版本的功能和质量门槛。领域术语以根目录 `CONTEXT.md` 为准，长期架构取舍以 `docs/adr/` 为准。

## 私有真实样本

真实 PDF 仅从开发者指定的仓库外目录读取，不复制到仓库、不提交 Git。自动化测试使用可公开、可重复生成的小型合成样本。

### 正向样本

| 样本 | 主要覆盖 | 预期 |
| --- | --- | --- |
| `building-ai-powered-products-for-true-epub-9781098152703.pdf` | 英文单栏正文、标题、列表、外部链接、PDF 元数据 | 成功生成可重排 EPUB，保留段落、语义样式、链接、书名和作者 |
| `01TPCUCT_AI 智能体：权威指南.pdf` | 横排中文、英文代码、列表、链接 | 成功生成可重排 EPUB，中文合并行不插入空格，代码和链接可读 |
| `Hello-Agents-V1.0.3-20260717.pdf` | 约 97.9 MiB、720 页、中文混排、链接、代码、水印 | 在 100 MiB 和 1000 页边界内完成；高置信度水印移除，否则产生可见警告 |
| `AI漫剧创作一本通_compressed.pdf` | 256 页、正文位于页面图片、文本层仅含重复水印 | 自动选择固定版式；每个源页面只输出一次，水印不作为独立正文，声明左右页与双页展开 |

## 功能验收

### 部署和认证

- Linux Docker 镜像能够启动，监听地址和端口可配置，并提供 `docker compose` 示例。
- 未登录用户不能访问上传、任务状态、取消和下载接口。
- 单账号凭据只从环境变量或密钥文件读取，不出现在源码、镜像层、日志或错误响应中。
- 登录建立安全会话；退出后会话失效。

### 上传和预检

- UI 支持选择或拖放一个 PDF，非 PDF、超过 100 MiB、超过 1000 页、受保护 PDF 和扫描型 PDF 显示明确错误。
- PDF 标题元数据有效时作为书名，否则使用去掉 `.pdf` 后缀的文件名；作者缺失时允许为空。
- 已有等待或转换中的任务时拒绝新上传，不建立排队队列。

### 任务生命周期

- 上传成功后返回任务标识，任务异步经历等待、转换中，并最终成功、失败或已取消。
- UI 每 2 秒轮询任务状态，展示真实处理阶段；可计算时展示已处理页数和总页数。
- 用户能够取消任务；取消和 30 分钟超时都必须终止子进程、清理临时文件并释放处理槽。
- 程序重启后不恢复任务；启动时清理上次运行遗留的临时文件。

### EPUB 内容

- 上传时支持自动、可重排和固定版式三种模式；默认自动选择。
- 自动模式对正文位于页面图片中的 PDF 生成固定版式 EPUB，对可靠文本型 PDF 保持可重排输出。
- 固定版式每个源页面生成一个视口页面，声明 `pre-paginated`、左右页和双页展开，不额外输出水印文本层。
- 自动模式输出可重排或固定版式 EPUB 3；可重排分支不复刻 PDF 固定分页，也不嵌入 PDF 字体。
- 第一页生成封面图，同时仍参与正文提取。
- 导航目录优先使用有效 PDF 大纲；无大纲时只推断高置信度标题，否则只生成“正文”入口。
- 视觉换行合并成段落；中文不插入多余空格，英文只在高置信度时合并行尾断词。
- 高置信度页眉、页脚和独立页码被移除；低置信度内容保留并可产生警告。
- 普通插图按阅读顺序保留；简单表格转为 XHTML，无法可靠结构化的局部表格或图形可降级为图片。
- 高置信度脚注生成双向跳转；无法匹配时仍保留脚注文字。
- 合法外部链接和可靠内部链接被保留，不安全或无法映射的链接只移除链接能力、保留可见文字。

### 成功、警告和失败

- 只有全部页面已处理、主要阅读顺序明确且 EPUB 通过规范校验时，任务才能成功并提供下载。
- 非致命降级作为转换警告展示，不静默忽略。
- 正文缺失、页面未处理、主要阅读顺序不明、EPUBCheck 失败或输出无法完整写入时，任务失败且不提供下载。
- 成功 EPUB、失败原因、警告和终态任务状态保留 1 小时，随后自动清理；PDF 副本和中间文件在任务结束时立即删除。

## 自动化验证

- Go 单元测试覆盖领域状态机、输入限制、段落重建、目录生成、链接过滤、EPUB 打包和清理规则。
- HTTP 集成测试覆盖登录、鉴权、上传、并发拒绝、轮询、取消、下载和过期响应。
- 合成 PDF 端到端测试覆盖英文、简繁中文、中英混排、标题、图片、简单表格、页眉页脚、脚注和链接。
- 所有成功产物必须通过 W3C EPUBCheck；至少使用一个常见 EPUB 阅读器人工检查正向真实样本。
- 提交前必须通过 `gofmt`、`go vet`、`go test ./...` 和 Docker 镜像构建验证。
