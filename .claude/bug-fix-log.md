# Bug 修复记录

## 2026-08-25：根页面循环重定向

- 现象：访问 `/` 时 `http.FileServer` 在 `/` 与 `/index.html` 的规范化逻辑之间持续返回 301。
- 原因：UI handler 将根路径手动改写为 `/index.html`，而 `FileServer` 会把显式 `index.html` 再重定向回目录路径。
- 修复：根页面直接从嵌入文件系统读取并返回，CSS/JS 等静态资源继续交给 `FileServer`。
- 验证：浏览器网络记录不再出现循环，根页面能够渲染登录界面。

## 2026-08-25：中文文件名导致 EPUBCheck 误报失败

- 现象：中文文件名 PDF 完成全部页面转换和 EPUB 打包后，任务在规范校验阶段失败；UI 只显示“EPUB 未通过规范校验”。
- 原因：容器未显式配置 UTF-8 locale，Java 将传给 EPUBCheck 的中文 EPUB 路径替换为问号，最终以 `File not found` 退出；生成的 EPUB 本身通过规范校验。
- 修复：校验前在任务目录内为 EPUB 创建纯 ASCII 硬链接并将该路径传给 EPUBCheck，校验后自动清理；容器同时声明 `C.UTF-8` locale，并在服务端日志保留内部失败原因。
- 验证：新增中文源路径回归测试；同一真实 PDF 生成的 177.8 MB EPUB 使用英文路径运行 EPUBCheck 5.3.0 时为 0 errors / 0 warnings。
